# 스킬 흐름 편집기 (대화 + 단계 카드)

사이드 패널의 **스킬 만들기**는 "대화 + 단계 카드" 편집기입니다. 말로 만들든, 해 보이든, 빈 흐름에서 시작하든, 실행에서 옮기든, 가져오든, 저장한 초안을 고치든 **같은 편집기**로 열립니다. 원문(SKILL.md)을 직접 고치는 화면으로 떨어지지 않습니다. 원문은 필요할 때 펼쳐 보는 고급 기능입니다.

스킬의 형식([05-skill-spec.md](05-skill-spec.md))과 실행 루프는 바뀌지 않았습니다. 이 편집기는 같은 문서를 더 편하게 만들고 고치는 도구입니다.

## 1. 사용 가이드

### 시작: 입구 세 가지

스킬 만들기 탭을 열면 큰 입력창 하나와 세 입구가 있습니다. 스킬 ID·이름·설명·담당 부서는 지금 묻지 않습니다. **저장할 때** "스킬 정보"에서 한 번에 정합니다.

| 입구 | 하는 일 |
|---|---|
| **말로 만들기** | 입력창에 업무를 설명하면 지금 탭의 화면을 읽고 모델이 초안을 씁니다. 이름·설명이 이미 채워져 나옵니다 |
| **해 보이기 (녹화)** | 업무를 한 번 해 보이면 그대로 단계가 됩니다. 녹화 중 화면의 표 읽기, 엑셀 채우기, 화면 정리, 말로 단계 추가를 쓸 수 있습니다 |
| **빈 흐름으로 시작** | 시작 화면과 보고 단계만 있는 흐름에서 직접 채웁니다 |

그 밖에 **SKILL.md 가져오기**, **내 초안의 고치기**, 실행 탭의 **이 실행을 스킬로 저장**도 같은 편집기로 열립니다.

### 단계 카드

단계마다 카드가 하나 있습니다. 번호, 종류(이동·누르기·입력·선택·표 읽기·엑셀 채우기·정리·내려받기·말로 적은 단계·보고), 한국어 제목이 보입니다.

- **카드를 누르면 펼쳐집니다.** 단계 문장(직접 고치기), 목적, 검사를 그 자리에서 고칩니다. 입력·선택 단계는 "실행할 때마다 입력받기"를 켜고 끄고, 입력의 이름·설명을 고칩니다.
- **순서 바꾸기**: 카드 왼쪽의 손잡이를 끌거나, 펼친 카드의 ▲▼ 버튼을 씁니다.
- **⋯ 메뉴**: 위/아래에 단계 추가(말로, 화면 정리, 표 읽기, 여기서부터 녹화), 복제, 삭제, 이 단계 말로 고치기.
- **카드 사이의 ＋**: 그 자리에 단계를 넣습니다.
- **1번 카드(시작 화면)** 는 잠겨 있습니다. 옮기거나 지울 수 없고 그 앞에 단계를 넣을 수 없습니다.
- **저장·상신 단계** 카드는 빨간 "승인 필요" 배지가 붙습니다. 실행할 때 이 버튼 직전에 사용자 승인을 받습니다.
- 위쪽에는 품질 등급(A~F)과 위험 등급(R1~R3)이 늘 보입니다. 경고 항목의 "그 단계 보기"를 누르면 해당 카드로 이동해 깜박입니다.

### 말로 고치기 (대화 입력)

화면 아래에 고정된 입력창에 말로 요청합니다.

- "3번 앞에 HOLD만 거르는 단계 추가, 라인 기본값은 8라인"
- "5번 단계를 지워 줘"
- "마지막 단계에서 표 말고 요약 한 줄로 보고해 줘"
- "표의 각 행마다 상태를 확인해 HOLD이면 사유를 적어 두는 단계를 조회 뒤에 넣어 줘" (반복은 이렇게 말로 씁니다)

카드가 바뀌고, 대화 기록에 **무엇이 바뀌었는지**와 **건너뛴 것(이유 포함)** 이 나옵니다. 모든 변경은 위쪽의 ↶ ↷ 버튼이나 `Ctrl+Z` / `Ctrl+Shift+Z`로 되돌리고 다시 합니다.

모델은 문서를 쓰지 않고 연산(넣기·고치기·지우기·옮기기·입력 추가·이름/설명)만 냅니다. 코드가 검증해 적용하므로 작은 모델도 형식을 깨지 않습니다.

### 여기까지 시험 (▶)

카드의 ▶는 **1번부터 그 카드까지의 단계**에 보고 단계만 붙여 임시로 **시험 실행**합니다. 저장하지 않고, 저장·상신 버튼은 누르기 직전에 멈춥니다.

- 필요한 입력값은 카드 안의 작은 폼에 받습니다 (기본값이 미리 채워짐. 엑셀 입력은 파일을 고름).
- 결과(성공/실패, 마지막 단계, 메시지)가 카드에 나옵니다. 실패하면 **이 결과로 말로 고치기**로 대화 입력에 이어 보냅니다. 방금 시험 결과는 다음 말로 고치기에 자동으로 함께 보냅니다.
- 시험 중에는 **중지** 버튼이 있습니다.
- 이 시험은 초안의 "시험 실행 통과" 기록, 실행 기록, 경로 기억을 남기지 않습니다. 배포 관문의 시험 실행은 저장한 뒤 실행 탭에서 합니다.

### 입력값 패널

"입력값" 접이식에서 스킬 입력의 이름, 라벨, 설명, 기본값, 형식, 필수를 표처럼 고치고 추가/삭제합니다. 이름을 바꾸면 모든 단계의 `{이름}`도 함께 바뀝니다. 단계 문장에 `{이름}`이 있는데 선언되지 않았으면 경고하고 **입력으로 추가** 버튼을 줍니다.

### 원문(SKILL.md)과 모델로 다듬기

"원문(SKILL.md) 보기·직접 고치기"를 펼치면 문서 전체를 직접 고칠 수 있습니다. 고치면 카드가 다시 만들어집니다. 문서를 단계로 열 수 없으면(형식 오류) 이유를 보여 주고 원문 편집만 열어 둡니다. **모델로 다듬기**(글만 다듬음), 품질 검사 상세, **초안으로 저장**은 그대로 있습니다.

### 녹화 끼워 넣기

카드 ⋯ 메뉴나 ＋의 **여기서부터 녹화**는 짧은 녹화 세션을 엽니다. 앞 단계까지의 화면이 이 탭에 열려 있어야 하고, 그 탭은 스킬의 사이트여야 합니다. **녹화 끝**을 누르면 녹화한 조각이 그 자리에 끼워집니다. 조각의 시작 이동·보고 단계는 버리고, 입력 이름이 겹치면 이름을 바꿔 알려 주며, 데이터셋 이름도 겹치면 바꿉니다.

## 2. 설계

### 문서가 정본, 카드는 단계 뷰

표현을 둘로 나누지 않습니다. **SKILL.md가 정본**이고, 카드 편집기는 그 문서의 `## 단계` 절을 보여 주고 고치는 뷰입니다. 그래서 녹화한 초안, 말로 만든 초안, 실행에서 옮긴 초안, 가져온 SKILL.md, 저장한 초안이 같은 편집기로 열립니다. 두 번째 생성 경로는 없습니다(말로 만들기는 `composeSkill`을 그대로 부릅니다).

- `src/core/flow.ts`: 문서 ↔ `Flow` 변환과 편집 연산. 브라우저에 의존하지 않는 순수 모듈입니다.
  - `parseFlow(source)`: 선언부(YAML 텍스트와 읽은 값), `## 단계`의 단계 블록(key, 머리, 인자 줄, 목적, 검사, 기록, 알 수 없는 줄), 단계 앞뒤의 나머지 본문을 읽습니다. 못 읽으면 예외 대신 `{ ok: false, reason }`을 돌려줍니다.
  - `renderFlow(flow)`: 단계를 1부터 다시 매기고 `submit_steps`를 블록 key를 따라 재매핑하며 `max_steps`가 `단계 수 × 3`보다 작으면 올립니다. 고치지 않은 곳은 글자 하나 바뀌지 않아 `renderFlow(parseFlow(s)) === s`(공백 정규화 외)가 성립합니다. 선언부는 줄 단위로만 고칩니다.
  - 연산은 모두 불변입니다: `moveBlock`, `insertBlock`, `removeBlock`, `duplicateBlock`, `updateBlock`, `setMeta`, `addInput`/`setInput`/`removeInput`, `spliceFlow`.
  - `History<T>`(되돌리기/다시 하기, 같은 종류의 연속 편집을 합치는 `coalesceKey`)와 카드 표현 `describeBlock`.
- `src/core/flow-words.ts`: 말로 고치기(`reviseFlowByWords`)와 말로 만들기(`createFlowByWords`).
- `entrypoints/sidepanel/Flow.tsx`(카드, 삽입 지점, 대화, 입력값 패널), `Author.tsx`(상태와 녹화), `flow-ui.ts`(보조).

### 보호 규칙 (통제)

편집 방식이 자유로워져도 통제는 코드가 지킵니다.

| 규칙 | 내용 |
|---|---|
| (a) 시작 단계 보호 | 1번(시작 화면 `navigate` + `url(...)` 검사)은 옮기거나 지울 수 없고, 그 앞에 아무것도 끼울 수 없다 |
| (b) 저장·상신 단계 삭제 | 지우면 `submit_steps`/`submit_labels`를 함께 정리한다. `risk`는 자동으로 바꾸지 않고 알림만 준다 |
| (c) 승인 표시 없는 저장·상신 | 저장·상신 버튼을 누르는 단계(`SUBMIT_PATTERN`)가 `submit_steps`에 없이 만들어지면 경고한다 (실행 때 그 버튼은 막힌다) |
| (d) 사이트 고정 | `domains`와 시작 URL은 편집기에서 바꾸지 않는다. 끼워 넣는 녹화도 스킬의 사이트에서만 한다 |
| (e) 모델이 만든 단계 | 인자 줄 없는 목표 단계만 가능하다. 인자 줄이 있는 단계의 문장은 말로 고치지 못한다(목적·검사는 가능) |

복제본은 "승인 필요" 표시를 물려받지 않습니다.

### 자유도: Claude 방식

스킬은 목표 문장들의 순서이고, 조건과 반복은 단계 문장으로 씁니다("표의 각 행마다 …", "데이터가 없으면 알리고 끝낸다"). 분기·반복 노드를 새로 만들지 않았고, 판단은 실행할 때 모델이 합니다. 빠른 경로(도구 + 인자)와 검사 식은 그대로 쓰므로 확실히 고정할 곳은 고정되고 나머지는 유연합니다.

### 말로 고치기의 연산

모델은 JSON 연산만 냅니다(`{"ops": [...]}`; 맨 배열도 읽음).

```
{"op":"insert","after":N,"text":"…","check"?:"…","note"?:"…"}
{"op":"update","n":N,"text"?:"…","check"?:"…","note"?:"…"}
{"op":"remove","n":N}      {"op":"move","n":N,"to":M}
{"op":"input","name":"…","label"?,"description"?,"type"?,"default"?}
{"op":"meta","name"?,"description"?,"tags"?}
```

번호는 모두 보여 준 처음 번호 기준입니다(앞 연산이 번호를 밀어도 같은 단계를 가리킵니다). 허용되지 않는 연산(1번 단계를 건드림, 인자 줄이 있는 단계의 문장 수정, 범위 밖 번호, 목표 단계에 쓸 수 없는 검사 식, 잘못된 입력 이름)은 버리고 `skipped`에 이유를 남깁니다. 모델 응답이 JSON이 아니면 사람이 읽을 오류를 보이고 흐름은 바뀌지 않습니다.

### 한계

- 말로 만들기가 스크립트(`scripts/`)를 만들어도 초안 저장은 `SKILL.md`만 저장합니다 (기존 초안 저장소와 같은 제한).
- 여기까지 시험은 앞 단계가 만든 상태(데이터셋 등)를 그 시험 안에서만 이어 갑니다. 화면은 실제 탭을 조작하므로 시험 뒤 화면 상태가 남습니다.
- 끼워 넣는 녹화는 앞 단계까지의 화면을 사람이 먼저 만들어 두어야 합니다.
