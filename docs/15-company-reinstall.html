회사 PC 재설치 안내

저장소를 받아 회사 PC에서 직접 빌드해 쓰는 경우의 순서입니다. 이번에 한 번만 다시 설치하면, 그 뒤로는 install\update.cmd 하나로 업데이트합니다. 관리자 권한은 필요 없습니다.

1 · 정리다른 폴더에서 로드한 Dogent 확장 삭제
2 · 설치build.cmd -Mode company -Install
3 · 로드%LOCALAPPDATA%\Dogent\extension
4 · 연결Native Messaging · 사용자 ID
이후update.cmd만 누름

왜 다시 설치하나

지금까지는 업데이트할 때마다 빌드하고, 크롬 확장을 지웠다가 폴더를 다시 지정해 로드했습니다. 확장을 저장소의 빌드 폴더(.output\chrome-mv3-company)나 판마다 이름이 다른 묶음 폴더(release\Dogent-company-<판>)에서 로드했기 때문입니다.

이제는 모든 부분을 늘 같은 곳(%LOCALAPPDATA%\Dogent)에 설치하고, 확장은 그 폴더에서 한 번만 로드합니다. 그 뒤로는 설치 프로그램이 폴더를 새 판으로 덮어쓰면 확장이 그것을 알아채고 스스로 다시 읽습니다.

무엇설치되는 곳업데이트할 때
브라우저 확장%LOCALAPPDATA%\Dogent\extension\폴더를 덮어쓰면 확장이 1분 안에 스스로 다시 읽음 (패널을 열면 바로)
데스크탑 앱%LOCALAPPDATA%\Dogent\Dogent.exe닫았다가 새 판으로 다시 띄움
오피스 도구 (Excel)%LOCALAPPDATA%\Dogent\dogent-office.exe덮어씀
터미널 클라이언트%LOCALAPPDATA%\Dogent\dogent.mjs · dogent 명령덮어씀
내 스킬 · 설정 · 실행 기록%USERPROFILE%\.dogent\건드리지 않음

준비물

필요한 것확인 방법없으면
Node.js 22 이상명령 창에서 node -v사내 소프트웨어 센터나 nodejs.org에서 LTS 설치 후 새 창을 엽니다
pnpmpnpm -v빌드 스크립트가 corepack enable pnpm으로 켭니다. 그래도 안 되면 npm install -g pnpm
git과 저장소저장소 폴더에서 git statusgit clone으로 받습니다. git 없이 옮겨 왔다면 업데이트 때 -NoPull을 씁니다
.NET Framework 4.xC:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe가 있는지Windows에 기본으로 있습니다. 없으면 오피스 도구만 빌드되지 않습니다
회사 빌드 설정저장소의 .env.company.local아래 2단계에서 만듭니다
크롬 또는 엣지둘 다 써도 됩니다

예전 것 정리 (한 번만)

  1. Dogent 앱을 닫습니다

    작업 표시줄의 Dogent 창을 닫습니다. 켜 둬도 설치 프로그램이 닫을지 묻고 닫습니다.

  2. 다른 폴더에서 로드한 Dogent 확장을 지웁니다

    chrome://extensions(엣지는 edge://extensions)에서 Dogent 카드의 세부정보를 눌러 소스 경로를 봅니다.

    • 경로가 %LOCALAPPDATA%\Dogent\extension(예: C:\Users\<나>\AppData\Local\Dogent\extension)이면 지우지 않습니다. 그대로 둡니다.
    • 저장소의 .output\…이나 release\Dogent-… 같은 다른 경로면 삭제를 누릅니다. 이번 한 번만 하면 됩니다.
    확장을 지우면 사이드 패널에 저장한 값(사용자 ID, 설정에서 더한 조작할 사이트, 클라이언트 연결 방식)이 지워집니다. 5단계에서 다시 넣습니다. 빌드에 넣은 모델 주소·키는 그대로 들어 있습니다.
  3. (선택) 목업 스킬 복사본을 지웁니다

    예전에 목업 사이트용 스킬(재공 확인 wip-*, hold-release, firewall-request)을 %USERPROFILE%\.dogent\skills\에 복사해 두었다면 지워도 됩니다. 지우지 않아도 회사 빌드에서는 "예시"로 숨겨집니다.

빌드하고 설치

  1. 최신 코드를 받습니다 
    cd D:\code\samsung\dogent      ← 저장소 폴더 (각자 위치)
git checkout main
git pull
  2. 회사 빌드 설정을 확인합니다

    저장소에 .env.company.local이 있는지 봅니다. 없으면 빌드 스크립트가 .env.company.example을 복사해 메모장으로 열어 줍니다. API 제공 측에서 받은 값을 넣고 저장합니다.

    WXT_LLM_BASE_URL=…/v1          ← api_base_url (/chat/completions 앞까지)
WXT_LLM_API_KEY=…              ← credential_key
WXT_LLM_MODEL=…
WXT_LLM_USER_TYPE=…
WXT_LLM_HEADERS='{"x-dep-ticket":"{key}", …}'
    WXT_SAMPLE_SKILLS=true 줄이 있으면 지웁니다. 목업 사이트 시연용이라 업무 PC에는 넣지 않습니다. 이 파일에는 키가 들어 있으니 저장소·메일·메신저로 옮기지 않습니다.
  3. 빌드하고 바로 설치합니다

    저장소 폴더의 install\build.cmd를 명령 창에서 옵션과 함께 실행합니다.

    install\build.cmd -Mode company -Install

    순서대로 진행됩니다: 준비물 확인 → (처음이거나 의존성이 바뀌었으면) pnpm install → 확장·클라이언트·오피스 도구·데스크탑 앱 빌드 → 묶음 release\Dogent-company-<판> → %LOCALAPPDATA%\Dogent에 설치 → 바탕화면·시작 메뉴 바로 가기.

    처음에는 의존성을 받느라 몇 분 걸립니다. 회사망에서 Electron을 받지 못하면 문제 해결의 ELECTRON_MIRROR를 봅니다. 빌드 전에 시험까지 돌리려면 -Test를 붙입니다.

확장 로드 (한 번만)

설치 단계가 끝나면 스크립트가 확장 관리 화면을 열고, 확장 폴더 경로를 클립보드에 넣어 둡니다. 다른 폴더에서 로드한 Dogent가 아직 남아 있으면 그 경로를 노란 글씨로 알려 줍니다.

  1. 개발자 모드를 켭니다

    크롬은 오른쪽 위, 엣지는 왼쪽 아래에 있습니다.

  2. 압축해제된 확장 프로그램을 로드합니다

    버튼을 누르고 폴더 칸에 Ctrl+V(경로 %LOCALAPPDATA%\Dogent\extension) → 폴더 선택.

  3. 툴바에 고정합니다

    퍼즐 조각 아이콘 → Dogent의 핀을 누릅니다.

  4. 설치 창으로 돌아가 Enter

    로드됐는지 확인하고 Dogent 앱을 띄웁니다. 앱은 처음 뜰 때 브라우저 연결(Native Messaging)을 스스로 등록합니다.

확장 ID는 늘 koofmoibafgagpofabagilbhknolfgok입니다. 어느 폴더에서 로드해도 같아서, 연결 등록이 그대로 맞습니다.

연결과 설정

  1. 확장을 앱에 연결합니다

    브라우저의 Dogent 아이콘 → 사이드 패널 → 설정 → 클라이언트 연결 → 방식 Native Messaging → 연결 설정 저장. 토큰은 자동으로 전달됩니다.

  2. 사용자 ID를 넣고 모델 연결을 시험합니다

    설정의 사용자 ID에 사내 SSO ID를 넣고 연결 시험 → "연결됨". 데스크탑 앱은 Windows 로그인 계정을 사용자 ID로 씁니다. 다르면 앱의 설정에서 고칩니다.

  3. 업무 화면을 점검합니다

    업무 화면을 열고 패널 위쪽 화면 점검을 누릅니다. 읽지 못하는 iframe이나 막히는 곳을 미리 알려 줍니다.

잘 됐는지 확인

  • 데스크탑 앱 왼쪽 위에 company · <판>이 보인다 (기본이면 회사 설정이 아닌 빌드입니다)
  • 앱 왼쪽 아래에 브라우저 이름(크롬, 엣지)이 보인다 = 확장과 연결됨
  • 앱 왼쪽 목록에 기본 스킬 4개(화면 요약, 화면 표를 엑셀로, 사이트 안에서 검색, 화면 입력 칸 채우기)와 팀·내 스킬이 보이고, 목업용 재공 스킬은 보이지 않는다
  • 확장 관리 화면의 Dogent 세부정보 → 소스가 …\AppData\Local\Dogent\extension이다
  • 사이드 패널의 연결 시험이 "연결됨"이다
  • "이 화면 요약해줘"를 앱에서 보내면 지금 브라우저 탭을 읽고 답한다
목록에서 안 보이는 스킬은 왼쪽 아래 스킬 관리에서 켜고 끕니다. 목업 사이트로 시연할 때만 예시 스킬 보이기를 켭니다. ☆을 누르면 자주 쓰는 스킬이 위에 고정됩니다.

그 뒤로: 업데이트

새 코드가 올라오면 저장소 폴더의 install\update.cmd를 두 번 누릅니다.

  1. git pull로 새 코드를 받습니다

    저장소에서 직접 고친 파일이 있으면 받지 않고 지금 코드로 빌드합니다 (git status로 확인).

  2. 바뀐 의존성만 다시 받고 모두 빌드해 덮어씁니다

    켜져 있던 앱은 묻지 않고 닫았다가 새 판으로 다시 띄웁니다. 모드는 지난번 것(처음은 company)을 씁니다.

  3. 확장은 손대지 않습니다

    1분 안에 스스로 새 판으로 바뀝니다. Dogent 패널을 열면 바로 바뀝니다(패널이 한 번 닫힙니다). 실행 중이면 끝난 뒤에 바뀝니다.

install\update.cmd                  ← 보통은 이것만
install\update.cmd -NoPull          ← git 없이 코드를 옮겨 왔을 때
install\update.cmd -Test            ← 빌드 전에 typecheck와 단위 시험
첫 업데이트 때 한 번 확인해 주세요. 업데이트 뒤 Dogent 패널을 열었을 때 패널이 한 번 닫혔다가 새 판으로 뜨면 정상입니다. 확장이 꺼져 있거나 옛 판 그대로면 확장 관리 화면에서 Dogent의 새로고침 ↻을 한 번 누르고 담당자에게 알려 주세요.

완전히 새로 설치하고 싶을 때

보통은 필요 없습니다. 설치 폴더가 꼬였다고 생각되면 지우고 다시 설치합니다.

%LOCALAPPDATA%\Dogent\uninstall.cmd          ← 프로그램, 바로 가기, dogent 명령, 브라우저 연결 등록을 지움
install\build.cmd -Mode company -Install     ← 다시 설치 (위의 "빌드하고 설치"부터)
uninstall.cmd -Purge는 %USERPROFILE%\.dogent(내 스킬, 설정, 실행 기록, 승인한 스크립트)까지 지웁니다. 내 스킬을 남기려면 -Purge 없이 씁니다. 확장은 확장 관리 화면에서 직접 삭제합니다.

문제 해결

증상원인과 조치
스크립트가 바로 닫히거나 "실행할 수 없습니다"더블클릭 대신 명령 창에서 install\build.cmd -Mode company -Install로 실행해 메시지를 봅니다. .cmd가 실행 정책을 우회해 PowerShell을 띄우므로 관리자 권한은 필요 없습니다.
.env.company.local 에 아직 채우지 않은 (…) 값이 있습니다메모장이 열립니다. (api_base_url) 같은 자리를 받은 값으로 바꾸고 저장한 뒤 다시 실행합니다.
pnpm install 실패회사망에서 패키지 저장소에 닿지 않는 경우입니다. 사내 npm 미러를 쓰면 npm config set registry <사내 주소> 뒤에 install\build.cmd -Mode company -Install -Reinstall.
Electron을 받지 못함사내 미러가 있으면 명령 창에서 set ELECTRON_MIRROR=<미러 주소> 뒤에 다시 실행합니다. 데스크탑 앱만 빼고 빌드하려면 -Parts extension,client,office.
C# 컴파일러(csc.exe)를 찾지 못함오피스 도구만 못 만듭니다. -Parts extension,client,desktop으로 나머지를 설치하고 Excel 기능은 쓰지 않습니다.
개발자 모드가 회색이거나 로드가 막힘회사 크롬 정책이 압축해제 확장을 막고 있습니다. chrome://policy에서 확인하고, 엣지로 시도하거나 IT에 허용을 요청합니다.
앱에 브라우저가 안 보임 (연결 안 됨)사이드 패널 → 설정 → 클라이언트 연결이 Native Messaging인지 보고 저장합니다. 확장의 소스 경로가 %LOCALAPPDATA%\Dogent\extension인지 보고, 아니면 지우고 그 폴더로 다시 로드한 뒤 앱을 다시 켭니다.
앱 왼쪽 위가 기본으로 보임-Mode company 없이 빌드했습니다. install\update.cmd -Mode company로 다시 설치합니다.
목업 재공 스킬이 여전히 보임앱의 스킬 관리에서 예시 스킬 보이기가 켜져 있는지 봅니다. 그래도 보이면 그 스킬이 localhost가 아닌 사이트도 다루는 것이니 스킬 관리에서 끕니다.
업데이트했는데 확장이 옛 판 그대로확장을 다른 폴더에서 로드했습니다. 위의 예전 것 정리 2번을 다시 봅니다. 맞는 폴더라면 Dogent 패널을 열면 바로 바뀝니다.
스크립트 스킬이 "Python 3이 없습니다"Python 스크립트를 쓰는 스킬입니다. Python 3을 설치하거나, 스킬 작성자에게 Node(.mjs) 스크립트로 바꿔 달라고 합니다. Node 스크립트는 앱에 든 Node로 돌아 따로 설치할 것이 없습니다.
