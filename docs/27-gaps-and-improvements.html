1. 한 줄 결론

기능은 계획한 범위까지 만들어져 있고 모의 환경에서는 끝까지 돕니다. 가장 큰 위험은 코드가 아니라, 사내 화면·사내 Gemma·사내 서버에서 한 번도 돌려 보지 못했다는 점입니다. 다음 일은 새 기능이 아니라 아래 P0를 사내 PC 1대에서 닫는 것입니다.

P0-7NASCA 저장 경로확장이 만드는 엑셀은 암호화되지 않음. 규정 확인 필요보안 부서 확인, saveThroughExcel 시험높음

연결·구조

#내용제안심각도
G1인증이 공유 토큰. Hub·사전·프록시·MCP 서버 모두 사내 SSO 연동이 없고, Hub는 클라이언트가 보낸 userId를 믿음SSO(또는 게이트웨이 헤더) 연동. 당분간 토큰 회수 절차 문서화중간
G2Hub·프록시가 파일 저장소, 단일 인스턴스. PostgreSQL은 스키마만 있고 구현 없음. 프록시 속도 제한은 프로세스 메모리복제가 필요해지면 Store를 PostgreSQL로 구현, 속도 제한은 공유 저장소로중간
G3서버를 놓을 곳·운영 주체·가동 보장이 없음. 사전·Hub·프록시·MCP 서버 4종이 모두 누군가 켜 둬야 함25 10장 항목 결정 (서버 위치, 인증, 보관 기간, 백업)높음
G4배포 채널이 여럿 (스킬 저장소, 사전 저장소, MCP 카탈로그). 정본 위치가 사람마다 다르게 이해될 수 있음정본을 문서로 못 박기. 스킬이 사전의 화면을 참조할 때 버전 검사 추가중간
G5포트 39217이 PC에 하나. 공용 PC·원격 데스크톱에서 두 번째 사용자가 못 뜸공용 PC가 있는지 먼저 확인, 있으면 사용자별 포트 또는 Native Messaging 전용중간
G6보관 기간 정리 작업 없음 (runs.jsonl, 프록시 감사 파일)삭제 주기를 보안 부서와 정하고 정리 스크립트 추가중간
G7통계 화면 없음 (Hub는 JSON API만)간단한 관리자 화면 또는 BI 연동낮음

이번에 들어간 새 기능의 빈 곳 (훅 · MCP 카탈로그 · 브라우저 실행)

#내용왜 문제인가제안심각도
N1훅은 개인 PC 파일만 (~/.dogent/hooks.json). 팀 공통 감사 훅·정책 훅을 배포할 길이 없음감사 기록을 모두에게 강제하려면 사람마다 직접 설정해야 함. 의도한 안전 선택이지만 운영에는 불편팀 훅은 Hub 정책으로 내려받되 "명령 실행"이 아닌 선언형(예: 막을 도구 목록)으로중간
N2훅 명령이 PC 권한으로 실행되고 시간 제한 10초만 있음. 샌드박스 없음모델이 만든 훅 명령을 사람이 확인하지 않으면 위험 (현재는 확인 필수)확인 창에 전체 명령을 보여 주는 현재 동작 유지, 사내 보안 검토 대상에 포함중간
N3훅은 고장 나면 막지 않음 (의도). 그러나 감사용 훅이 죽으면 기록이 조용히 빠짐감사 목적이면 "기록 실패 시 중단"이 필요할 수 있음훅별 failClosed 옵션 검토낮음
N4MCP 카탈로그 서버가 command형이면 이 PC에서 임의 명령 실행. 서명·해시 검증 없음. 저장소에 쓸 수 있으면 모든 사용자에게 설치 후보를 올릴 수 있음설치는 사람이 내용을 보고 확인하므로 자동은 아니나, 확인 피로가 생기면 사고command형은 별도 승인 라벨, CODEOWNERS 강제, 설치 로그를 Hub로높음
N5카탈로그는 설치만. 업데이트 알림, 버전, 제거(dogent mcp remove는 있으나 카탈로그와 연결 없음)가 없음서버 주소/권한이 바뀌어도 사용자 설정이 낡음카탈로그 항목에 version 추가, dogent mcp outdated중간
N6requires_env 환경 변수는 사용자가 직접 설정. 없으면 설치 전 알려 주지만 값을 안전하게 넣는 길이 없음setx로 평문 토큰이 환경에 남음자격 증명 관리자(Windows Credential Manager) 연동중간
N7카탈로그 예시 mes-lots의 주소가 https://mes-mcp.example.corp (가짜 주소)그대로 올리면 연결 실패실제 서버가 생기기 전까지 샘플임을 표시, 실제 주소로 교체낮음
N8MCP 카탈로그·훅 관리는 터미널 중심. 데스크탑 앱에 화면이 없음비개발자는 쓰기 어려움앱 설정에 MCP 탭(목록·설치·권한), 훅 탭중간
N9브라우저 자동 실행은 Windows만, 브라우저 이름은 chrome/edge만. 띄운 뒤 확장이 붙기까지의 대기·실패 안내는 약함프로필 선택(여러 프로필), 사내 설치 경로 차이사내 PC에서 확인, 프로필 지정 옵션낮음
N10신규 기능의 사내 환경 검증 0건 (훅의 실제 보안 SW 반응, 카탈로그 raw 주소·토큰 방식 등)다른 기능과 같은 위험P0 이후 같은 방식으로 확인중간
