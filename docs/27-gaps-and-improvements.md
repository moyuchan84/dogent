# Dogent 부족한 부분과 보완 계획

> 기준일 2026-11-09 · 기준 코드: main (PR #42 반영 후) · `pnpm test` 637개 통과, `pnpm typecheck` 오류 없음 (오늘 실행)
> 이전 현황은 [19-project-status-and-checklist.html](19-project-status-and-checklist.html)(2026-11-03, 시험 589개)이며, 그 뒤에 들어간 훅·`/명령`·계획 먼저·MCP 카탈로그·브라우저 자동 실행은 아직 그 문서에 반영되지 않았습니다 (3장).

## 1. 한 줄 결론

**기능은 계획한 범위까지 만들어져 있고 모의 환경에서는 끝까지 돕니다. 가장 큰 위험은 코드가 아니라, 사내 화면·사내 Gemma·사내 서버에서 한 번도 돌려 보지 못했다는 점입니다.** 다음 일은 새 기능이 아니라 아래 P0를 사내 PC 1대에서 닫는 것입니다.

| 구분 | 현황 |
|---|---|
| 자동 시험 | 단위·통합 637개 통과. 실제 크롬 e2e 35개, 브리지 e2e 11개 (11-03 기준) |
| 사내 환경에서 검증한 것 | **0건** |
| 시험의 한계 | 모의 사이트·모의 모델·로컬 Ollama·실제 Excel. 모의 모델은 절차를 규칙으로 따라갈 뿐 판단 능력을 검증하지 못함 |
| 사내 업무 스킬 | **0개** (번들 4개는 범용, 업무 스킬은 모의 사이트용 샘플) |
