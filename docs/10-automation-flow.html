DOGENT · DO-AGENT

말로 시키면, 사내 화면과 엑셀에서 대신 해 주는 업무 에이전트

업무를 아는 사람이 스킬(업무 절차서)로 큰 흐름을 정하고, 화면 상황과 값은 에이전트가 맞춥니다. 판단은 클라이언트, 브라우저 조작은 크롬 확장, NASCA 문서는 Excel이 맡습니다. Claude Code와 Claude in Chrome이 나뉘어 있는 것과 같은 구조입니다.

흐름 따라가기

시나리오를 고르고 다음을 누르면 구성도 위에서 요청이 어디로 흐르는지 보입니다. 구성도의 상자를 누르면 그 부분이 하는 일과 하지 않는 일이 나옵니다.

정한 것 (D1~D9)

누르면 이유가 나옵니다. 자세한 내용은 저장소의 docs/09-client-architecture.md에 있습니다.

안전장치

어떤 클라이언트가 붙든(Claude Code 포함) 확장과 실행 엔진이 직접 지키는 규칙입니다.

조작할 사이트만설정에 등록한 사이트 밖으로는 이동하지도, 읽지도 않습니다. 사이트는 크롬 권한 요청으로 더하고 뺍니다.
저장·상신은 사람이 승인스킬에 선언된 단계와 버튼만, 확장의 승인 창에서 승인해야 누릅니다. 시험 실행은 그 직전에 멈춥니다.
비밀번호는 사람이로그인 화면을 만나면 멈추고 알립니다. 에이전트는 비밀번호 칸을 읽거나 입력하지 않습니다.
넣은 값은 다시 읽어 대조입력한 뒤와 상신 직전에 화면 값을 원본과 비교합니다. 다르면 멈춥니다.
표 데이터는 모델에 보내지 않음표는 PC 안에 두고 Gemma에는 컬럼 이름과 샘플만 줍니다. 가공은 로컬에서 합니다.
입력값 규칙스킬의 policy.yaml(IP 대역, 금지 값, 숫자 범위)을 실행 전에 검사합니다.

진행 단계

지금의 확장 단독 버전으로 회사에서 쓰면서, 구조를 하나씩 나눠 갑니다.

  1. 지금확장 단독사이드 패널 안에서 판단·조작. 녹화, 엑셀 입력, 승인, 화면 점검, 사내 Gemma 연결까지 사용 가능
  2. 1단계 · 진행 중확장 = 브라우저 도구브리지, MCP 도구, Native Messaging·WebSocket, 승인 창. Claude Code에 붙여 시험
  3. 2단계Dogent 클라이언트터미널 프로그램. Gemma, 스킬 폴더, 목표 단계, 잘 된 실행을 스킬로
  4. 3단계오피스 도구 (C#)Excel COM으로 NASCA 문서 열기·읽기·쓰기·저장
  5. 4단계데스크탑 화면Electron. 현업이 터미널 없이 사용. 패널은 승인·진행 표시
